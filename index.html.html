Threat Landscape — 2008 → 2025

2008
Kaminsky Attack
16-bit Transaction ID = 65,536 combinations. UDP brute-force enables cache poisoning. Port randomization introduced — later proven bypassable.
2024 — IEEE S&P
TuDoor — Pre-processing Logic Flaw
24 resolvers affected. VCP: <1s cache poisoning (349ms, Microsoft DNS). VDS: zero-bandwidth DoS. Port randomization rendered irrelevant.
2025 Q1 — ACM CCS
RebirthDay + BIND Bailiwick CVE
ECS Birthday Paradox: 365K+ resolvers vulnerable (CVE-2025-5994). BIND CVE-2025-40778: 1–2 packets poison AD/banking records for 24h.
2025 Q2
MCP Inspector RCE — CVE-2025-49596 (CVSS 9.4)
AI agent + DNS rebinding = localhost WebSocket RCE. Zero-click. Corporate DB exfil via MCP server.
20 Jun 2025
Root Server BGP Hijack — AS35168
8 root servers hijacked. 90-minute window. RPKI ROA existed — ROV not enforced. First known direct root server BGP hijack.
